# TONY - Assistente Vocale 🎙️

Un assistente vocale intelligente in italiano, alimentato da AI.

## Come Utilizzare l'Applicazione

### Opzione 1: Utilizzare tramite Replit (Consigliato)
1. Accedi a [Replit.com](https://replit.com)
2. Apri questo progetto
3. Clicca su "Run" nella parte superiore
4. L'applicazione si avvierà automaticamente nel browser

Vantaggi:
- Non richiede installazioni sul tuo computer
- Funziona su qualsiasi dispositivo con un browser
- Sempre aggiornato

### Opzione 2: Esecuzione Locale (Per Sviluppatori)
Se sei uno sviluppatore e vuoi eseguire l'applicazione localmente:

1. Assicurati di avere Node.js installato
2. Clona il repository
3. Esegui lo script di avvio:
```bash
./start.sh
```

## Funzionalità
- 🗣️ Riconoscimento vocale in italiano
- 🤖 Integrazione con AI per risposte intelligenti
- 🔊 Sintesi vocale naturale in italiano
- 💡 Interfaccia utente intuitiva

## Come Interagire con TONY
1. Apri l'applicazione nel browser
2. Clicca sul pulsante del microfono
3. Di "TONY" seguito dal tuo comando
4. Ascolta la risposta vocale

Esempio: "TONY, che tempo fa oggi?"
